# Competency Based Test · Practice

A 67-question practice test for Pinellas County's Grade 6 Accelerated Math
Competency Based Test, covering all 57 Florida B.E.S.T. benchmarks on the
test flyer. Built in the Everyone Loves Math notebook style.

Single self-contained `index.html` — fonts and brand art are inlined.
Progress saves in the browser (localStorage) so a student can close the tab
and resume.

Live: https://everyonelovesmath.github.io/cbt-practice/
